# first-night-once · 첫날 「피 묻은 손등」 반복 줄이기

브랜치 `feat/first-night-once`

## 왜

2026-11-26 실서버 확인: 기록 없이 첫날 메시지 3개를 보냈더니 답장 3개가 모두 손등의 피를 묘사했다.
원인은 첫날 밤 사정 블록(FIRST_NIGHT)이 1일째 **모든 답장**에 붙었기 때문이다.

## 바뀐 파일

| 파일 | 내용 |
| --- | --- |
| `engine.py` | `FIRST_NIGHT_TURNS = 3`. 기록의 유저 메시지가 3개보다 적을 때만 FIRST_NIGHT 를 넣는다(1일째 조건은 그대로) |
| `yoon_seoa_prompt.md` | FIRST_NIGHT 에 한 줄 추가: 손등의 피는 한 번 보였으면 다시 묘사하지 않고, 치료했거나 화제가 바뀌었으면 꺼내지 않는다 |
| `tests/test_first_night.py` | 처음 3턴만 들어감, 그 뒤·2일째·에피소드에는 없음, 새 문장이 들어감 (5개) |

## 확인

- `python -m unittest discover -s tests`: 85개 중 새 5개 포함 통과. `test_llm_fallover` 1개는 작업 환경에 Google 라이브러리가 없어 불러오기 실패(코드와 무관, 전과 같음).
- 실서버 확인은 병합·배포 뒤 첫날 메시지를 다시 보내서 본다.

## 제가 정한 것

- 기준을 3턴으로 정했다. 오프닝에서 서아가 손등을 내밀고, 유저가 보통 1~2턴 안에 치료하거나 화제를 돌리기 때문이다.
- 오프닝 문장(손등을 내미는 장면)은 고정 원고라 그대로 두었다. 오프닝은 기록으로 계속 들어가지만, 지시 블록이 빠지고 「다시 묘사하지 않는다」가 있어서 반복이 줄어든다.
