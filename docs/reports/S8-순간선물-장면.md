# S8 순간 선물을 장면에 연결

2026-11-28 · 브랜치 `feat/s8-moment-scenes`

실제 플레이에서 따뜻한 수건 순간이 한 번도 열리지 않았습니다. 지금까지 순간 선물은 모델이 `gift_moment` 를 낼 때만 열렸습니다. 이제 정해진 장면 답장에서는 서버가 확실히 엽니다. 모델이 스스로 여는 기존 경로는 그대로이고, 선물 이름·가격·단계·반응 몸짓, 원고 대사, 크리스마스는 바꾸지 않았습니다.

## 장면 표 (`MOMENT_SCENES`, 본편만)

| 선물 id | 서버가 여는 답장 | 판정이 「열었다」고 기록하는 때(`used_events.MOMENT_{id}`) |
| --- | --- | --- |
| `towel` | 「[다음 밤]」 첫마디 중 `NIGHT_START_3_TEASE`·`NIGHT_START_3_CARE` 답장 / `STORM` 장면 시작 답장(pending_event STORM) | 그 「[다음 밤]」을 판정할 때 / STORM 시작 답장을 판정할 때 |
| `flower`(바 여분 열쇠) | ALLEY 장면이 「마침」이 된 판정 바로 다음 답장(한 번). 그 판정이 `used_events.MOMENT_DUE_flower` 를 둠 | 다음 판정에서 기록하고 차례를 지움(목록에 없었어도 차례는 지움) |
| `umbrella` | 위기 소식 답장(pending_event CRISIS). 소식이 안 나와서 다시 넣는 CRISIS 답장에도 함께 | `crisis_news` 가 true 가 될 때(소식이 답장에 나옴, 또는 3번 안 나와서 나간 것으로 볼 때) |
| `ring` | 연인 물음 답장(pending_event LOVERS_ASK, 원고 1절) | 물음 답장을 판정하는 차례에 다시 넣지 않고 넘어갈 때(물음이 나왔거나, 3번 시도했거나, lovers_yes) |

- 그 답장에서는 앱이 보낸 `state.gift_moments` 안에 그 id 가 있어야 열고, 장면 선물이 모델 값보다 우선합니다(모델이 null 이거나 다른 선물을 냈어도). 모델이 같은 id 를 냈으면 모델의 reason 을 그대로 쓰고, 아니면 reason 은 그 선물 이름입니다.
- 목록에 없거나(이미 줌·쿨다운·방금 순간 선물을 줘서 쉬는 중) 이미 `MOMENT_{id}` 가 있으면 열지 않습니다. 이때는 모델이 낸 값이 그대로 갑니다.
- `firstaid`·`cocktail` 은 지금 그대로(모델만 엶).
- 크리스마스(episode)에서는 열지도 기록하지도 않습니다.

반지를 건네면: lovers 가 ask·wait 일 때 유저 메시지에 `[유저가 선물함: 반지` 와 `순간 선물` 이 함께 있으면, 판정 모델이 flag 를 안 붙여도 서버가 `lovers_yes` 를 더합니다 → 6단계(S7 흐름 그대로, STAGE_UP_6 앞에 2절).

## 바뀐 지시 문장 (`yoon_seoa_prompt.md`)

1. `JUDGE_SYSTEM` — `lovers_yes` 줄 바로 아래 한 줄:
   「서아가 관계를 물은 뒤 유저가 반지를 건네면 lovers_yes 다.」
2. `LOVERS_WATCH` — 마지막 줄 뒤 한 줄:
   「유저가 반지를 건네며 대답하면 원고 2절(갈래별)로 받되, 지문에 반지를 받는 대목(반지를 내려다보다가 손가락에 끼운다 등)을 한 문장 넣는다.」
3. `GIFT_MOMENT` — 「장면과 맞물리는 때」 줄:
   - 전: 1단계 서아가 다쳐서 온 밤(구급상자), 3단계 폭우·비에 젖어 온 밤(따뜻한 수건), 4단계 그 골목·처음 이름을 부를 때(바 여분 열쇠), 5단계 빗속에서 떠나려는 서아를 붙잡을 때(우산), 6단계 남기로 한 뒤(반지).
   - 후: 1단계 서아가 다쳐서 온 밤(구급상자), 며칠 뒤 밤, 비에 젖어 들어왔을 때 · 폭우 장면(따뜻한 수건), 그 골목 이야기를 마친 뒤(바 여분 열쇠), 위기 소식을 꺼냈을 때(우산), 서아가 관계를 물을 때(반지).

## 제가 정한 것

1. **기록은 판정이 합니다.** `/chat`(reply)은 state 를 돌려주지 않아서 `MOMENT_{id}` 는 그 장면 답장을 판정할 때 `used_events` 에 씁니다. 「열었다」는 그 판정 state 의 `gift_moments` 에 그 id 가 있었는지로 봅니다(앱 목록이 답장 때와 판정 때 같다고 봄). 목록에 없어서 못 연 장면은 기록하지 않으므로, 수건은 며칠 뒤 밤에 못 열었으면 STORM 에서 열 수 있습니다.
2. **열쇠 「한 번」.** 골목 마침 판정이 `used_events.MOMENT_DUE_flower` 를 두고, 그동안 `judge_soon` 을 true 로 해서 다음 답장 하나만 열리게 했습니다(새 state 키는 만들지 않음). 다음 판정에서 차례를 지웁니다.
3. **열쇠와 다른 장면 선물이 겹칠 때.** 골목을 마친 같은 판정에서 5단계로 올라 위기 소식(CRISIS)이 다음 답장이 되는 경우가 흔합니다. 한 답장에 선물은 하나라서 그 답장의 장면 선물(우산)을 먼저 열고, 열쇠는 그 바로 다음 답장으로 미뤘습니다(그 한 번만). 우산이 목록에 없으면 위기 소식 답장에서 열쇠를 엽니다. 우선순위는 그 답장의 장면(밤 첫마디·사건) → 골목 뒤 차례.
4. **우산은 소식이 확인될 때까지 다시.** 「확인 전이면 소식 답장을 낼 때 함께」를 따라 CRISIS 답장마다 엽니다. 소식이 답장에 없어 CRISIS 를 다시 넣으면 우산도 다시 열리고, `crisis_news` 가 true 가 될 때 기록합니다.
5. **STORM 시작 답장.** 갈래 STORM 과 6단계 무작위 STORM 모두 pending_event STORM 이라 같은 블록이므로 둘 다 수건을 엽니다(이미 열었으면 안 엶). 시작 답장 하나가 예비 지문 「…」이었으면 기록하지 않습니다.
6. **반지 건넴 판정을 서버도 함.** 지시의 판정 문장을 넣고, 판정 모델이 놓쳐도 되도록 서버가 `[유저가 선물함: 반지` + `순간 선물` 을 보면 `lovers_yes` 를 더합니다. ring 이 LOVERS_ASK 와 함께 열렸는지는 따지지 않고 lovers ask·wait 중 순간 선물로 건네면 받아 줌으로 봅니다(wait 중 모델이 스스로 반지 순간을 연 경우도 같음). 「순간 선물」이 안 붙은 그냥 건넴은 판정 모델에 맡깁니다. 이름은 앱 목록의 ring 이름, 목록에 없으면 「반지」로 찾습니다.
7. **reason.** 서버가 연 순간의 reason 은 선물 이름(모델이 같은 id 를 냈으면 모델의 reason).
8. **GIFT_MOMENT 문구의 단계 표시.** 새 때 문구에서 「3단계」「4단계」 같은 단계 표시는 지시 문구대로 뺐습니다. 구급상자 줄은 지시에 없어 그대로 두었습니다.

## 앱 팀에 전할 것

1. **ring 은 5단계 lovers ask 에서도 순간 선물 목록(`state.gift_moments`)에 들어 있어야 합니다.** 지금 「6단계 남기로 한 뒤」에만 넣고 있다면, lovers 가 `ask`·`wait` 일 때(stage_label 「고백」)도 넣어 주세요. 없으면 서버가 반지 순간을 열지 않습니다. 같은 식으로 towel 은 3단계 며칠 뒤 밤·STORM, flower 는 4단계 골목 마친 뒤(5단계 위기 첫 답장 뒤일 수도 있음), umbrella 는 5단계 위기 소식 때 목록에 있어야 합니다.
2. **각 선물의 `when` 문구**(모델이 보는 글, 서버는 그대로 넣음)를 장면에 맞춰 주세요: towel 「며칠 뒤 밤, 비에 젖어 들어왔을 때 · 폭우 장면」, flower 「그 골목 이야기를 마친 뒤」, umbrella 「위기 소식을 꺼냈을 때」, ring 「서아가 관계를 물을 때」.
3. **반지 건넴 메시지 모양**은 지금처럼 `[유저가 선물함: 반지] · 순간 선물` 이어야 합니다(이름이 바뀌면 목록의 name 으로 찾음).
4. **`used_events` 에 새 키**(`MOMENT_towel` 등, `MOMENT_DUE_flower`)가 들어갑니다. 지금처럼 받은 state 를 그대로 돌려보내면 됩니다. 「처음부터」·되감기 때는 지금 하던 대로 used_events 를 비우거나 되돌려 주세요.
5. **`judge_soon`** 이 골목을 마친 직후 한 번 더 true 가 됩니다(열쇠를 다음 답장 하나에만 열기 위해). 지금처럼 true 면 답장마다 판정하면 됩니다.
6. 같은 장면에서 앱이 쿨다운으로 이미 그 선물을 목록에서 뺐다면 서버는 열지 않습니다. 장면에서 확실히 열리게 하려면 쿨다운이 장면 선물에 걸리지 않게 봐 주세요.
