# 보고서 · Gemini 사용량 기록 (feat/usage-log)

기획 팀이 운영 원가(대화 1회당 비용, 유저당 원가, 손익분기)를 계산할 수 있게 서버가 Gemini 사용량을 직접 기록한다.

## 바뀐 파일
| 파일 | 내용 |
|---|---|
| `usage.py` (새) | 호출마다 종류·모델·토큰을 메모리에 더하고 Render 로그에 한 줄. 가격표로 예상 비용 계산 |
| `llm.py` | 응답이 오면 `usage_metadata`(입력·출력·생각·캐시 토큰)를 기록. 모든 모델이 실패하면 실패 1회로 셈. 기록이 실패해도 대화는 그대로 |
| `server.py` | `GET /usage` 추가 |
| `.env.example` | `USAGE_PRICES` (가격이 바뀌면 덮어쓰기) |
| `tests/test_usage.py` (새) | 9개 |

## 보는 법
- **지금까지 합계**: 브라우저로 `https://seoa-backand.onrender.com/usage`
  - `totals`: 종류별 호출 수·토큰 (chat = 서아 답장 = 유저 메시지 수, judge = 관계 판정, summary = 요약)
  - `by_model`: 실제로 답한 모델별 호출·토큰·예상 비용
  - `per_user_message`: 유저 메시지 1개당 평균 입력·출력 토큰, 판정·요약 횟수, **판정·요약 몫까지 넣은 1개당 예상 비용**
  - `days`: 날짜(한국 시간)별
- **호출 하나하나**: Render 로그에서 `[usage]` 로 검색
  `[usage] kind=chat model=gemini-3.5-flash-lite in=5210 out=96 think=0 cached=0`
- **실제 청구액**: AI Studio Spend 화면 (이쪽이 정답, `/usage` 는 가격표로 계산한 예상값)

## 확인 결과
- 키 없는 테스트 285개 통과 (새 9개: 종류·모델별 합계, 넘김 뒤 실제 모델, 실패 횟수, 메타데이터 없음, 기록 오류에도 답장, 가격 덮어쓰기, 한국 날짜 나눔, 키·대화 내용 없음, `/usage` 응답)
- 점검(eval)은 돌리지 않음(지시에 없음, Google 한도 아낌)

## 제가 정한 것
- **판정과 요약 구분**: 둘 다 판정 모델을 쓰지만, 판정은 JSON(`json_mode=True`), 요약은 글이라 그걸로 나눴다. 엔진 코드는 안 건드림.
- **출력 비용에 생각(thinking) 토큰 포함**: Google 가격표가 출력 가격에 생각 토큰을 포함한다.
- **가격표**: 2026-11 Google 가격표 기준 (3.5 Flash-Lite 0.30/1.50, 3.1 Flash-Lite 0.25/1.50, 3.5 Flash 1.50/9.00 달러/100만 토큰). 3.5 Flash-Lite 는 AI Studio 가격표에 없어 Google Cloud 가격을 썼다. 가격표에 없는 모델은 `unpriced_models` 에 나오고 비용 0 으로 센다.
- **저장은 메모리 + 로그**: 무료 Render 는 잠들거나 다시 배포하면 디스크·메모리가 비워져 합계가 0 부터 다시 센다(`since` 가 그 시각). 그래서 호출마다 로그 한 줄을 남겨 긴 기간도 다시 셀 수 있게 했다. 외부 DB 는 넣지 않음.
- **`/usage` 는 공개**: 숫자만 있고 키·대화 내용·IP 는 없다. 숨기고 싶으면 다음에 토큰을 붙일 수 있다.
- **유저 수는 못 셈**: 서버는 상태가 없고 유저를 구분하는 값을 받지 않는다. 「유저당 원가」는 (유저 1명이 보통 보내는 메시지 수) × `per_user_message.est_cost_usd_all_in` 으로 계산.
