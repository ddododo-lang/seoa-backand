# 보고서 · 이름 구분 (feat/name-clarity)

테스터 의견: 「제가 설정한 이름이랑 캐릭터 이름이 명확하게 구분이 안 되는 부분이 있다」.
앱 [108] 보고서에서 앱은 이름을 `state.user_name` 으로 제대로 보내고 있어 서버 프롬프트 쪽으로 넘어온 건.
테스터 캡처는 받지 못해, 서버에서 이름이 섞일 수 있는 곳을 찾아 막았다.

## 원인으로 본 곳
1. **지문의 1인칭**: 속마음을 「서아 시점 혼잣말」로 쓰게 돼 있어, 지문에 「나는·내가」가 들어가면 유저(「당신」)와 서아 중 누구인지 흐려짐.
2. **지문에 유저 이름**: 규칙으로는 금지인데, 모델이 「○○ 씨가…」처럼 어겨도 막는 장치가 없었음.
3. **요약문**: 요약기가 유저를 이름·「유저」·「당신」 등으로 섞어 쓸 수 있고, 그 요약을 서아가 다시 읽음.
4. **이름 겹침**: 유저가 이름을 「서아」「마리」「태오」처럼 등장인물과 같게 정하면 구분할 방법이 없었음.

## 제가 정한 것
- **지문의 유저 이름은 「○○ 씨」꼴만 코드로 바꿈.** 이름만 나온 것까지 바꾸면 「하늘」「별」 같은 이름이 「하늘이 밝아 온다」까지 「당신이 밝아 온다」로 바꿔 버림. 이름만 나온 경우는 프롬프트 규칙으로 막음.
- **이름 겹침은 막지 않고 알려 줌.** 이름은 앱이 정하는 값이라 서버는 바꾸지 않음. 겹치면 서아는 유저를 늘 「○○ 씨」로 불러 인물과 나눔(평소 규칙의 「진지할 때 이름만」보다 우선).
- 「다른 인물」 규칙에 마리·태오 이름을 쓰지 않음: 공통 규칙이라 크리스마스 에피소드에도 들어가고, 에피소드에는 본편 인물 이름을 넣지 않는 규칙(S1)이 있음.
- 크리스마스 에피소드도 이름 겹침 줄이 똑같이 들어감.
