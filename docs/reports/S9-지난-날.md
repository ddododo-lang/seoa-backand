# S9 지난 밤에서 지난 날 알려 주기

2026-11-28 · 브랜치 `feat/s9-night-gap`

「며칠 뒤 밤」 카드 뒤에 서아가 「하루밖에 안 지났는데」처럼 말한 문제. 프롬프트에 지난번 밤에서 얼마나 지났는지 한 줄을 더했습니다. 원고 대사, 밤 넘기기 규칙, 시간 카드 문구, 크리스마스는 바꾸지 않았습니다. eval_chat 은 돌리지 않았습니다.

## 바뀐 것

- 새 state 키 `night_gap`(기본 `None`): 「[다음 밤]」(또는 「[다음 밤]」 없이 NIGHT_WAIT_MAX 가 지나 서버가 넘길 때)로 밤을 넘기면 NIGHT_NEXT 의 넘기는 날 수가 1 이면 `"하루"`, 2 이상이면 `"며칠"`. 다음 밤을 넘길 때까지 그대로.
  - 2일째 밤(NIGHT_START_2) → 하루 · 며칠 뒤 밤(NIGHT_START_3_TEASE·CARE, RIFT_NIGHT) → 며칠 · 첫날 밤 → None
- 프롬프트 STATE_BLOCK 「일차」 줄 바로 아래, 값이 있을 때만:
  - 하루: `- 지난번 밤에서: 하루가 지났다. 지난번 밤의 일은 「어제」로 말한다.`
  - 며칠: `- 지난번 밤에서: 며칠이 지났다. 지난번 밤의 일은 「어제」「하루」가 아니라 「며칠 전」「그날」로 말한다.`
  - 값이 없으면 줄을 통째로 뺌. 크리스마스(episode)는 EPISODE_STATE 를 쓰므로 들어가지 않음.

## 바뀐 파일

- `engine.py`: 상수 `NIGHT_GAP_LINES`, `new_state` 의 `night_gap`, `normalize_state`(하루·며칠 밖의 값은 None), `_next_night`(값 정함), `_build_system`(줄 넣기·빼기).
- `yoon_seoa_prompt.md`: STATE_BLOCK 의 `- 지난번 밤에서: {{night_gap}}` 줄, 치환 변수 표에 `{{night_gap}}`.
- `tests/test_s9_night_gap.py`(새, 6개).

## 제가 정한 것

- 줄 문구는 프롬프트에만 있고, state 에는 짧은 값 `"하루"`·`"며칠"` 만 둠(앱이 다루기 쉽게).
- `normalize_state` 는 `"하루"`·`"며칠"` 이 아닌 값을 None 으로 바꿈. 되감기로 예전 state(키 없음)가 오면 None → 줄 없음. 이 경우 2일째 이후라도 줄이 빠지지만, 다음 밤을 넘기면 다시 생김.
- 크리스마스 중에도 키는 받은 대로 돌려보냄(본편으로 돌아왔을 때 그대로 쓰도록). 프롬프트에만 넣지 않음.
- 「[다음 밤]」 없이 서버가 넘기는 경로(NIGHT_WAIT_MAX)도 같은 함수를 지나므로 같은 값을 둠.

## 앱 팀에 전할 것

- state 에 새 키 `night_gap`(`null` | `"하루"` | `"며칠"`)이 옵니다. 받은 state 를 그대로 돌려보내면 됩니다. 앱이 값을 정하거나 보여 줄 필요는 없습니다.
- 되감기 때 저장해 둔 state 를 보내면 그 시점의 값이 쓰입니다.
