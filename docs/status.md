## 지금 서버 규칙 요약 (본편)

- 단계: 1 경계 → 2 티키타카 → 3 썸 → 4 고백 직전 → 5 위기(엇갈림) → 6 연인. 실패 엔딩 없음.
- 2→3·3→4·4→5 는 그 단계 갈래 장면(장난 DATE·STORM / 다정 WALK_HOME·ROOFTOP / 공통 ALLEY)을 **실제로 마쳐야** 오름(시작 답장 + 유저 메시지 3개 정상 답장). 갈래가 없으면 갈래 사건 차례에 서버가 정함.
- 밤 넘기기: 1→2, 2→3 뒤 마무리 → 「[다음 밤]」. 밤 넘기기 중에는 단계가 안 오름.
- 위기: 소식 답장 뒤 메시지 6개 안에 마음 확인 → 연인, 아니면 엇갈림 → 며칠 뒤 밤 → 메시지 6개 → 화해의 문 → 사과·진심(앞서 한 것 포함) → 연인.
- 단계 기록: 정상으로 마친 단계마다 한 문장(받은 recent 의 그 단계 구간으로), 요청은 목록으로 유지.
- 테스트: `python -m unittest discover -s tests -v` → 231개 통과 (FakeLLM, 키 없음).
