## 지금 서버 규칙 요약 (본편)

- 단계: 1 경계 → 2 티키타카 → 3 썸 → 4 고백 직전 → 5 위기(엇갈림) → 6 연인. 실패 엔딩 없음.
- 2→3·3→4·4→5 는 그 단계 갈래 장면(장난 DATE·STORM / 다정 WALK_HOME·ROOFTOP / 공통 ALLEY)을 **실제로 마쳐야** 오름(시작 답장 + 유저 메시지 3개 정상 답장). 갈래가 없으면 갈래 사건 차례에 서버가 정함.
- 단계가 오르면 상징 장면(이름이 있으면 3단계는 이름 장면)이 답장에 나온 것을 확인할 때까지 다음 답장에 다시 넣음(그 단계 메시지 3개까지). 확인 전에는 judge_soon true.
- 밤 넘기기: 1→2, 2→3 뒤 상징 장면 답장 다음부터 메시지 8개(임시) → 마무리 → 「[다음 밤]」. 밤 넘기기 중에는 단계가 안 오름. 작별은 마무리에서 한 번.
- 장소: 서버가 대신 채우는 location 은 지문에 이동 대목이 있을 때만(장면 세 번째 답장은 그대로).
- 속마음 힌트: 넣기 직전에 단계·조건을 다시 봐서 맞지 않으면 안 넣음.
- 위기: 소식(「새벽에 떠나」)이 답장에 나온 것을 확인한 뒤(안 나오면 다시, 3번까지) 메시지 6개 안에 마음 확인 → 연인, 아니면 엇갈림 → 며칠 뒤 밤 → 메시지 6개 → 화해의 문 → 사과·진심(앞서 한 것 포함) → 연인. 문 뒤 판정에 `withdraw`(명확한 거부)가 있으면 그 판정에서는 화해 안 함.
- 단계 기록: 정상으로 마친 단계마다 한 문장(받은 recent 의 그 단계 구간으로), 요청은 목록으로 유지.
- 갈래 장면 마침: 정상 답장 4개(시작 + 3). 앱이 `reply_ok` 를 보내면 true 수로, 안 보내면 묶음 수 − 마지막 「…」.
- 테스트: `python -m unittest discover -s tests -v` → 308개 통과 (FakeLLM, 키 없음).
